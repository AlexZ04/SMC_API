# API для Спортивно-массовой комиссии ППОС ТГУ

Репозиторий предоставляет открытую API для создания ботов на любой поддерживаемой платформе.

## Текущая версия системы: v0.1.0

## Предназначение системы *[100%]*
Инфраструктура бота Спортивно-массовой комиссии ППОС ТГУ имеет следующую архитектуру:
1) Данная API является центральным элементом системы и выступает в роли проводника сценариев для адаптеров*.
2) Основная коммуникация системы осуществляется через сообщения в группе ВК комиссии
3) Административная панель системы реализована в виде бота в Telegram
4) Для взаимодействия между данной API и внешними API необходимо реализовать **адаптер**, 
который будет выполнять роль связующего звена между API комиссии и API платформы, на которой развёрнут бот
5) Система может быть реализована на любой платформе, предоставляющей открытую функциональность для разработки ботов, 
с использованием универсального ответа системы, содержащего как содержательную часть сообщений для пользователей,
так и предполагаемое описание UI

* Адаптер - прослойка между API бота комиссии и API системы, в которой реализуется бот 

## Функциональность системы для пользователя (вк) *[100%]*
1) Получить ответ на FAQ
2) Задать вопрос администраторам СМК
3) Настроить подписки на рассылки - об изменении расписания физкультуры, об мероприятиях СМК и об играх своего структурного подразделения
4) Перейти к форме заполнения обратной связи
5) Получить помощь по работе бота
6) Подать заявку на участие в розыгрыше (если данная функция активирована администраторами)

## Функциональность админ-панели (тг) *[100%]*
1) Изменить текст рассылки о мероприятиях СМК
2) Изменить текст рассылки об играх своего структурного подразделения
3) Изменить текст про спортивных организаторов
4) Посмотреть текст рассылки (обоих типов)
5) Изменить ссылки на расписания
6) Отправить рассылку (обоих типов)
7) Посмотреть статистику системы
8) Привязать свой ВК
9) CRUD администраторов системы
10) Активировать систему розыгрышей 
11) Провести розыгрыш

## Структура проекта *[100%]*
1) В директории *diagrams* представлены диаграммы системы
2) Директория *docs* содержит в себе спецификацию OpenApi и примеры ответов системы
3) Директория *release-notes* содержит в себе описание добавленной функциональности системы
