1) Для изменения тогглов следует придерживаться формата (файл - список данных тогглов):
```
{
    "active": false,
    "description": "Тоггл для переключения функциональности розыгрыша",
    "toggleName": "Розыгрыш"
}
```

2) Необходимо добавить файл с названием faculties.json, в котором перечислить все факультеты и их спорторгов.
Пример:
```
[
  {
    "id": 0,
    "nameRu": "Не установлен",
    "sportsOrgName": "-",
    "sportsOrgLink": "-"
  }
]
```

3) Для добавления предсозданных администраторов требуется добавить файл admins-list.json, в котором будут перечислены 
все администраторы и суперадминистраторы

Пример:
```
[
  {
    "platform": "TG",
    "idOnPlatform": "super-admin",
    "role": "SUPER_ADMIN"
  }
]
```
